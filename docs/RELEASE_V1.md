# PolkaPets app v1

Rama de trabajo creada desde `codex/integracion-total` en el commit `a124ca8`.

Incluye el juego local del ajolote, el modo NFT conectado a Polkadot Hub TestNet,
la dirección de contrato `0x758425A3b756079B34FF97cB9C7A764fD44C008a`,
el logo de la aplicación y los cambios de interfaz de Guillermo hasta la versión 2.1.

La dirección responde como PolkaPets (PPET), con una sola especie y cero mascotas al
momento de la comprobación. Pendiente: obtener el archivo Solidity exacto del despliegue
para compararlo con el fuente y la ABI del repositorio antes de anunciar equivalencia de código.
